# Past Projects: 

This section has the past projects I've worked on since this websites inception. 

**rclone -> Google Drive sync for Fedora Linux:** The project that necessitated the creation of this website, this one simply connects my Google Drive to rclone. I: Takes in my google drive, and uses rclone with a custom pathway through the google API. O: A folder in my linux file explorer that mounts to my google drive! This folder is fully synced with the drive, so updates to it effect the drive, and vice versa. 
This was a fun project because I had to publish a single-user app through google's cloud services. The app effectively acts as a highway through googles API and into my account, allowing rclone to efficiently sync my files. I followed the guide at this link: https://rclone.org/drive/
